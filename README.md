# homebrew-tap

Homebrew casks for Tuuli, Kaiku, Kiito and Mittari, the macOS apps at https://apps.partiti.dev.

```sh
brew install --cask gabry-ts/tap/tuuli
brew install --cask gabry-ts/tap/kaiku
brew install --cask gabry-ts/tap/kiito
brew install --cask gabry-ts/tap/mittari
```

The apps update themselves once installed, so `brew upgrade` is only needed if you prefer it.
